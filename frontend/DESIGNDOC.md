## Color Scheme
- A monochromatic color scheme (Official name - Monocore)
- Use the Monocore dark color scheme with these exact values:

BACKGROUNDS
  #101010  — deepest bg (editor base, title bar, activity bar)
  #161616  — active tab, hover widget bg
  #181818  — editor, sidebar
  #1C1C1C  — inputs, inlay hints
  #232323  — list selection
  #282828  — list hover

TEXT / FOREGROUND
  #DADADA  — primary text
  #B0B0B0  — secondary / muted text
  #808080  — subtle / tertiary text
  #505050  — very muted (e.g. line numbers)

ACCENT (use for interactive elements, highlights, CTAs)
  #FFC799  — primary accent (warm peach/orange)
  #FFCFA8  — accent hover state

SEMANTIC
  #FF8080  — error / destructive
  #FFC799  — warning (same as accent)
  #50B5AA  — success / info (teal)
  #FF7300  — active/live state (e.g. debugging)

TOKEN / SYNTAX (for code blocks)
  #DADADA  — variables, plain identifiers
  #FFC799  — functions, class names, keywords
  #50B5AA  — strings
  #B0B0B0  — operators, punctuation
  #FF8080  — errors, invalid
  #8b8b8b  — comments (can apply ~58% opacity)
